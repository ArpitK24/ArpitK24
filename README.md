# Hi, I'm Arpit 👋

### AI Systems & Full-Stack Engineer · Building agents, dev tools & products

I build AI-powered developer tools and full-stack products, mostly in **Go, Python and TypeScript**. Lately that means coding agents, LLM orchestration and context engineering: making models see more of what's actually going on.

📍 Bengaluru · 🔭 Building [Forge](https://github.com/ArpitK24/forge) · 🧠 Learning agent harness architecture, LLM inference & serving, graph-based context systems · 🤝 Open to collaborating on AI agents, dev tools and LLM infra

## 🛠️ What I'm building

| Project | What it is | Stack |
|---|---|---|
| **[Forge](https://github.com/ArpitK24/forge)** | A context engine for code, in your terminal. Coding agent for any OpenAI-compatible model, shipped as a single static binary | Go |
| **[OwnKey](https://github.com/ArpitK24/OwnKey)** | Local-first AI coding agent CLI for codebase analysis and suggestions. On npm | TypeScript |
| **[Been-There](https://github.com/ArpitK24/Been-There)** | Know who's been there before you. A trusted graph of real-world experiences | TypeScript |
